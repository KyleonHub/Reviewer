# Reviewer - Rizal's Life and Works (RLW)

An interactive, responsive, and mobile-optimized reviewer for **Rizal's Life and Works (RLW)**.

## Features
- Mobile Optimized: Built with touch-friendly targets (≥48px), responsive layout, and prevented mobile auto-zoom.
- Dark Mode Default: Clean minimalist UI with dark mode support.
- Study Modes:
  - Flashcards: Interactive cards with flip animation, recall rating, hints, and historical imagery.
  - Randomizer Quiz: Mixed pool combining multiple question types with randomized sequence and shuffled choices (MCQ, True/False, Identification, Matching Type).
- Comprehensive Question Bank: 167 questions & 65 flashcards covering the entire course syllabus.
- Local Historical Visuals: Embedded historical photographs and illustrations for supported learning.

## Getting Started
Open index.html directly in your browser, or on Windows double-click START_REVIEWER.bat.
