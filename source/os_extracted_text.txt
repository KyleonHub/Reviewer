What is Operating System? 
An Operating System (OS) is an interface between a 
computer user and computer hardware. 
An Operating System (OS) is a collection of software 
that manages computer hardware resources and 
provides common services for computer programs.

Components of OS 
• Process Management 
• File Management 
• Network Management 
• Main Memory Management (RAM) 
• Secondary Storage Management 
• I/O Device Management 
• Security Management 
• Command Interpreter System (Shell) 
Process Management 
It handles the creation, scheduling, termination, 
synchronization, communication and deadlock 
handling of processes. 
Process - a running or active program 
File Management 
It is responsible for creating, deleting, reading, 
writing, and organizing and backing up files on 
storage media. 
Network Management 
Network management oversees communication 
between computers over a network. It ensures data is 
transmitted between computers reliably and efficiently. 
Main Memory Management 
It handles the allocation and deallocation of memory 
space to various processes. This ensures that each 
process has enough memory to execute while 
optimizing the overall use of available memory. (RAM 
temporary data) 
Secondary Storage Management 
Responsible for managing data storage on hard drives 
and other storage devices. It offers secondary storage 
to back up the main memory. (SSD keeps data) 
I/O Device Management 
Responsible for managing all input and output 
devices, such as keyboards, mice, printers, monitors, 
and storage devices. The OS handles communication 
between the computer and these devices, ensuring 
efficient and error-free data transfer. 
Security Management 
Security management protects the computer system 
from unauthorized access and ensures data 
integrity. 
Command Interpreter System 
This is the part of the OS that interacts with the user, 
accepting commands and executing them (CLI or GUI). 
It acts as a bridge between user input and OS functions.

Properties of an Operating System 
MULTITASKING 
Multitasking is the ability of an OS to run multiple 
applications at the same time. 
HOW IT WORKS: 
• The CPU time is divided into tiny slices. 
• The OS uses a scheduler to switch 
between active tasks every few 
milliseconds. 
• Each app gets a time slice to use the 
CPU. 
MULTI-USER 
A multi-user OS allows multiple people to use 
the same system—either simultaneously (like on 
a server) or one after another with separate 
profiles. 
HOW IT WORKS: 
• The OS maintains separate user accounts 
and permissions. 
• It keeps each user's files, apps, and 
settings private. 
• In servers, resource sharing is done in 
real-time with user isolation. 
MULTITHREADING 
• Multithreading is the ability of an OS to 
run different parts (threads) of the same 
program simultaneously. 
HOW IT WORKS: 
• Each program can be split into smaller 
tasks (threads) that run at the same time. 
Threads share the same memory, making 
programs faster and more efficient. 
MULTIPROCESSING 
Multiprocessing means the OS can use more 
than one processor (CPU or core) at the same 
time to complete tasks in parallel. 
HOW IT WORKS: 
• The OS splits tasks into chunks and sends 
them to different CPU cores. 
• This makes execution faster and 
smoother, especially for demanding 
applications. 
PORTABILITY 
A portable OS can run on different types of 
hardware platforms with little or no change in its 
code. 
HOW IT WORKS: 
• Written in high-level languages (like C). 
• Developers can compile the OS for 
different processors (Intel, ARM, etc.) 
TIME-SHARING 
Time-sharing means multiple users or tasks get a 
small time slot with the CPU so they can work "at 
the same time" from the user's perspective. 
HOW IT WORKS: 
• The OS gives each user or process a time 
quantum. 
• It switches between them using round-
robin scheduling. 
• If one task takes too long, it is paused and 
the next gets CPU time. 
DISTRIBUTED 
A distributed OS manages a group of 
independent computers and makes them look 
like a single system to the user. 
HOW IT WORKS: 
• Uses networking to connect multiple 
systems. 
• Tasks are distributed to different 
machines. 
REAL-TIME 
A Real-Time OS (RTOS) can respond to events 
within a guaranteed time frame— delays are not 
acceptable.

HOW IT WORKS: 
• Prioritizes critical tasks (interrupts) over 
non-critical ones. 
• Processes data as it comes, with low-
latency response time. 
• Often used in embedded systems where 
timing is crucial.
